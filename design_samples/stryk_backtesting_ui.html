Provenance · 05 / 05
What came from where

The best of three, in one identity

Each borrowed pattern is a proven backtesting convention — adopted, then re-skinned to Midnight Teal. None changes STRYK's engine.

ALGOTEST
Live Payoff & Analysis panel beside the legs — Max Profit / Max Loss / Breakevens / Risk-Reward / Prob-of-Profit, plus per-leg Greeks (Δ Θ Γ V). You see the strategy's shape before you ever run it.
STOCKMOCK
Chart-tab switcher + customizable trade table — one chart frame flips between Equity / Payoff / Drawdown / Monthly / Rolling-straddle; an "Addons" menu compresses P&L, sorts by exit, toggles columns.
QUANTMAN
Objective-driven optimizer — pick parameters, a method, an objective; a live master-summary table ranks every combo with progress (36 / 36 tested). Fast, legible iteration.
STRYK
The identity that ties it together — Midnight Teal palette, lightning mark, left rail, MAE/MFE & exit-reason badges (your differentiators) carried into every table. Familiar to any AlgoTest user, unmistakably STRYK.
