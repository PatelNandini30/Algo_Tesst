Field Research

How the best desks present complexity

Surveyed elite quant firms, retail options platforms, and 2025–26 fintech dashboard practice.

FIRMS Quant houses

Jane Street, Two Sigma, Optiver. Restrained palette + a single strategic accent (Jane Street's red hexagons, Optiver's orange). Card-based modular grids, sans-serif clarity, a geometric signature motif. Intellectual rigor — not cold minimalism.

PLATFORMS Options tools

Opstra = dense pro terminal, max tools per screen. Sensibull = clean drag-and-drop, beginner-first. TradingView = powerful charts + robust backtesting. Two valid poles: density vs. guidance.

FINTECH Dashboard UX

Card grids, top-banner KPIs, side panels for related functions, progressive disclosure, sticky left-rail actions. The 2026 shift: arrange the UI around the user's decision workflow, not the tool's internal structure.

Principles distilled for STRYK

01  One accent, used with discipline. Blue carries identity & action; green is reserved for profit & confirm. Everything else is structure.

02  Let density be a choice, not a default. Offer both a guided path and a terminal-dense path — same features underneath.

03  Disclose progressively. Summaries first, depth on demand — advanced toggles, lazy legs, MAE/MFE fold away until needed.

04  Results live beside the decision. The faster config→result feels, the more strategies a user tests.

Recommendation

The minimum set worth shipping

You don't need all seven. Three coordinates cover every user without touching the engine.

SHIP NEXT

③ Cockpit

Persistent split-pane results beside the existing two-column config. Biggest workflow gain, smallest rebuild — reuses every current component.

OPTIONAL MODE

④ Flow

A "Guided mode" toggle for newcomers. Same fields, walked one step at a time. Lives beside Studio, not instead of it.

POWER TOGGLE

② Terminal

A "Dense view" for pros — everything on one screen. Add later; Cockpit's split already does most of the work.

Decision in one line

Keep Studio as the home, add Cockpit's live split-pane, and expose Flow + Terminal as view toggles — one set of features, three densities, zero logic changed.
