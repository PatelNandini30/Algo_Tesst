● Here's what was happening and why it was so slow:

  Root cause - the 2018 backtest took 25 minutes:

  1. The Rust cache (native.load_cache) was building a HashMap with ~4.3 million

  "2018-01-11"). Each String is a heap allocation. For 4.3M rows = 34 million 
  heap allocations, consuming ~650MB of RAM.
  2. Your machine has 16GB RAM shared between Docker containers. When Rust tried
   to allocate 650MB while other containers (Postgres, Redis, Python workers)
  were already using memory, the OS started swapping to the HDD. HDD swap is
  1000x slower than RAM — this turned a 13-second operation into 25 minutes.
  Celery eventually killed it after hitting the 25-minute soft time limit.
  3. The 2019 request showing 2020 data: the spot price feather (used to find
  ATM strike) only covered data from 2020 onwards, so spot lookups for 2019
  dates returned Nothing → no ATM → no trades.

  - Replaced String keys with compact integer keys (i32, u16, i64, u8, i32) —

  time: 0.11s (was 12.86s; was 25 min under swap).
  2. Spot range check (backend/services/rust_fast_path.py): Added check — if
